Sobre este Sistema Web

Desenvolvido em arquivo único utilizando HTML5 Semântico, CSS3 (Tailwind + Keyframes) e JavaScript Vanilla (ES6+). Conta com roteamento SPA (Single Page Application) entre 3 visualizações, operações completas de CRUD (Criar, Ler, Atualizar e Excluir), máscaras de entrada, validação em tempo real e persistência local no navegador.
